About Me

Thank you for taking the time to explore my portfolio!

I'm a final year Software Engineering for Business student at the University of the West of England, currently working part-time as a Junior Software Developer at OpusApeiro alongside my studies, having previously completed a Year in Industry at Callen-Lenz.

Outside of my degree and job roles, I build full-stack projects, from Flask applications with real database design (Where To?) to a Go-powered recommendation engine with a custom scoring algorithm (Backpacker's Guide).

Below are the technical skills I would like to highlight.

Go

Used Go as my main language during my software rotations at Callen-Lenz, and now applying this independently to build a algorthim backend for Backpacker's Guide.

Python & Flask

Built and deployed full-stack Flask applications (this portfolio, Where To?), handling routing, templating, form processing, and database integration.

SQL & Databases

Worked with PostgreSQL during job roles, and independently designed a relational schema for Backpacker's Guide, and implemented a Neon database integration on Where To?.

Git

Used Git for version control across individual projects and university group work, and continued using it professionally in my developer roles including GitLab, GitHub and Azure DevOps repositories.

HTML & CSS & JavaScript

Built responsive, accessible page layouts across every project in this portfolio.

Java

Gained a strong foundation in object-oriented design through university coursework, particularly a second-year project focused on OOP principles, building on first-year Java experience.
