Backpacker's Guide - South America

Backpacker's Guide is an individual project that helps travellers plan a multi-country backpacking trip across South America without needing to build a spreadsheet from scratch. Rather than generating a rigid, "perfect" schedule, it gives users a data-driven starting point — a suggested route, duration, and set of destinations — based on their own preferences, which they can then adjust to taste.

How it works: Users provide their total trip length, preferred countries, interest tags (e.g. adrenaline, culture, nature), budget level, and travel pace. A weighted scoring algorithm then evaluates each candidate destination against those preferences — combining an interest-match score, activity bonuses, budget and pace fit, and a distance penalty — to produce a ranked, personalised itinerary. Day allocation is handled through a constraint-based heuristic: minimum stay requirements are satisfied first, and any remaining days are distributed toward the highest-scoring destinations.

Status: In active development, version controlled on GitHub. The data modelling, loading and mapping layers are implemented and unit-tested. Next up: the scoring algorithm and database connections, followed by UI design and a connected React frontend. The repository is currently private while the project is in development.

Architecture

  • Backend (Go): A layered pipeline separates raw database models from the enriched structures the algorithm actually reasons about. A dedicated loader layer builds lookup maps (tags → destinations, tags → activities, activities → destinations) and transforms flat relational data into algorithm-ready structs — keeping the scoring logic decoupled from the database schema.
  • Database (PostgreSQL): A relational schema models countries, destinations, activities, and a flexible tagging system, where destinations and activities can each carry multiple tags, allowing many-to-many matching between user interests and locations.
  • Frontend (React, planned): An interactive map and editable itinerary table, where users can adjust day counts, remove destinations, or swap countries, with live warnings if their edits exceed their available time.
